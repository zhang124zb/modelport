# 对话设置

在“设置 → 对话设置”中调整全局对话偏好；输入框旁的设置图标也可直接打开本页。修改只在点击“保存设置”后生效；退出页面、关闭设置或退出软件前会提示未保存内容。恢复默认只重置本页表单，仍需保存，不删除会话、技能或知识库。

## 首版选项

- 发送快捷键：默认 Enter 发送、Shift + Enter 换行；也可改成 Ctrl + Enter 发送、Enter 换行。中文输入法选词不触发发送；Ctrl 模式同时支持系统的 Meta 修饰键。
- 历史上下文：默认最近 20 轮，范围 0–40。一轮是一条问题与一条完整回复；失败、停止、中断、未完成和孤立消息不作为完整问答。0 轮只发送本次问题，不删除历史，也不关闭技能或知识库。这是问答轮数，不是模型 Token 容量。
- 全局提示词：默认空白，最多 4000 字符；用于保存后的下一次请求。先加入基础指令，再加入当前选用技能，知识库约束和命中数据继续由原生层组装。更换指令建议新建对话；旧消息不会改写。
- 回复展示：默认 Markdown，可切换纯文本。纯文本显示原文，不渲染 HTML；显示方式同时作用于已有回复。
- 消息字号：默认 15 px，范围 12–24 px。作用于聊天消息主体，状态、来源和控制按钮保留各自字号；Markdown 的标题和代码保留自身层级样式。

云端请求会发送全局提示词、选中的技能正文、限定范围的历史，以及知识库命中片段（按原有流程确认）。提示词不要包含 API Key 或其他秘密。没有配置提示词时，不添加新的 system 消息。

## 存储与生效

独立保存于当前 WebView 的 `modelport.preferences.chat.v1`，不混入聊天、API Key 或资料库，不上传 Git，不跨设备同步。提示词未加密。保存失败不改变当前生效配置；格式损坏时临时展示默认配置并显示警告，原数据保持不变。用户检查并明确保存前暂停发送，避免默认值意外带入更多历史；只有明确保存才覆盖原数据。

输入和展示选项保存后立即生效；上下文和提示词只影响下一次发送，不改变正在生成的请求。默认值不主动写入存储，新字段缺失时使用默认值，未知字段不保留。

首版没有 Temperature、Top P、输出 Token 限制或关闭流式请求选项，继续使用各模型的默认生成参数并保留停止生成能力。不同模型的参数支持尚未统一，后续按提供方能力接入，不发送虚假的配置参数。

## 开发入口

- `src/lib/chat-settings.ts`：配置类型、校验、版本化存储、快捷键判定及完整问答裁剪。
- `src/features/settings/ChatSettingsPage.tsx`：草稿、保存、恢复默认和公共退出保护。
- `SettingsPageProps`：`chatSettings`、`chatSettingsError`、`onSaveChatSettings`。
- `src/App.tsx`：已保存配置、输入操作、展示更新及本次请求快照。
- `src/lib/modelport.ts`：普通 / 流式聊天末尾增加可选 `systemPrompt`，兼容原调用。
- `src-tauri/src/connection.rs`：`send_chat` / `stream_chat` 接受可选 `system_prompt`，共同校验长度和控制字符；历史仍仅接受 user / assistant 角色。

## 验证

- `node scripts/verify-chat-settings-store.mjs`：Node.js 24；校验、损坏数据保护、保存失败、输入法快捷键与上下文裁剪，不读写实际本机资料。
- `cargo test --locked --manifest-path src-tauri/Cargo.toml --lib`：提示词边界、默认行为、技能 / 知识库及原有流式流程。
- `node scripts/verify-chat-settings.mjs <调试端口> [截图路径]`：仅全新独立 WebView 配置；保存 / 退出保护、存储失败、重启、样式 / 字号、真实 Ollama 指令和上下文、恢复默认及损坏配置恢复。脚本结束恢复本次测试前的设置和聊天，不修改技能 / 知识库或调用云端付费模型。
