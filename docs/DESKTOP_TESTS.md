# 一键桌面回归

目的：真实桌面界面 → 原生命令 → 临时本机模型 / MCP 服务 → 聊天保存 → 重启显示，验证完整交互，不仅检查代码能否编译。

## 使用

需要 Windows x64、Node.js 24、PowerShell 7、WebView2 及当前版本已构建程序。无需真实 API Key、Ollama 或下载模型。在项目根目录运行：

```powershell
npm run test:desktop
```

默认检查 `release/ModelPort.exe`。检查调试程序：

```powershell
npm run test:desktop -- -Executable src-tauri/target/debug/modelport.exe
```

脚本不自动编译；改过源码后先构建。版本检查拒绝明显不匹配的程序，但同版本旧 EXE 仍可能过期，所以不能把版本一致代替完整重建。

## 自动覆盖

串行运行 7 组已有或补充的桌面检查，不同时操纵同一个窗口：

- `verify-desktop-ui.mjs`：等待初始化、整窗遮罩 / 模糊、Ollama 无密钥输入、12 类设置、最小窗口与关闭后焦点。
- `verify-keyboard-shortcuts.mjs`：8 项快捷键、保存 / 退出保护、输入法、仅保存无 API 调用、会话循环 / 搜索、话题 / 重试上下文与真实原生 HTTP 流。
- `verify-chat-recovery.mjs`：损坏 / 读取失败不覆盖、发送 / 附件清理暂停、原始数据实际下载、取消 / 无效 / 失败恢复、明确恢复 / 重置，以及相似代码块、中文 Markdown 表格、公式与图表显示。
- `verify-chat-performance.mjs`：千条历史分页 / 滚动、单会话写入、402 段回复合并、停止 / 重启保留文字及损坏子记录保护。
- `verify-providers.mjs`：内置 / 自定义连接、模型发现、本机 HTTP / 路径、独立凭据、主机修改保护、取消和删除引用。
- `verify-mcp.mjs`：服务默认停用、精确授权参数、默认拒绝、允许 / 拒绝 / 停止、过期授权、Schema 校验、禁止重定向及惰性历史不重放。
- `verify-composer-layout.mjs`：选择区同排、长名称、最小窗口和键盘管理入口。

模型和工具测试服务只监听 `127.0.0.1` 随机端口，回复为合成内容。不调用真实云端，不更改技能 / 知识库，也不为了测试关闭现有 Ollama。原生层真实保存的临时提供商 / MCP 配置按本次 UUID 清理；合成令牌只用于凭据隔离测试，不使用或展示已有真实密钥。

## 隔离、记录与失败

每次新建 `release/desktop-regression-<UUID>/webview`，只对子进程设置测试 WebView 数据目录及回环调试端口，之后恢复环境变量。单个检查也确认没有真实历史；工具不接入用户日常窗口。调试端口可控制测试窗口，只在本机临时测试期间开启，完成后关闭本次窗口，不能用于日常启动或开放给其他设备。

失败立即停止后续检查。各检查有明确断言；控制台输出和每组日志、`report.json` 保留在该次测试目录，UI 检查失败时还保存截图。报告区分总组数、已运行数量、通过状态和耗时，未运行的组不会被算作通过。所有这些目录被 Git / 便携打包忽略，不公开上传。

正常结束和抛错时，检查恢复测试前聊天 / 偏好，清理自己创建的配置，主脚本只关闭此次启动的进程，保留失败资料供排查。强制终止终端、断电或进程崩溃无法保证 `finally` 执行，可能留下以“回归临时提供商 / MCP 安全验证”等命名的临时配置；应在设置中核对来源再删除，不能批量删除已有配置。脚本不宣称后台服务 / 工具权限被系统沙箱隔离。

## 边界

这是一键本机自动化，不代表所有真实提供商、识图、系统拖动 / 窗口行为或所有辅助技术已经验证。原有真实 Ollama / GitHub 集成脚本按各功能文档额外运行。GitHub CI 仍执行类型、离线逻辑、前端构建及原生测试；尚未把需要桌面会话 / WebView2 的流程默认加入托管 CI，不在缺少 GUI 环境时静默跳过并宣称通过。

程序包的独立安全检查：

```powershell
pwsh -NoProfile -File scripts/verify-package-guards.ps1 -PackagePath release/ModelPort-0.12.0-windows-x64.zip
```

先验证原包，再只在本次临时副本中加入额外资料 / 篡改 EXE，验证检查器拒绝异常；原包不修改。构建与发布见 [README](../README.md) 和 [GitHub 文档](./GITHUB.md)。
