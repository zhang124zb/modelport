# 常规设置

在“设置 → 常规设置”配置应用外观和启动界面。只在点击“保存常规设置”后生效；切换分类、Escape、关闭设置或关闭原生窗口时保护未保存修改。恢复默认只重置本页表单，仍需保存，不改变对话设置、快捷键、凭据或资料库。

## 外观和启动

- 主题：默认浅色，可选择深色或跟随系统。保存后立即作用于聊天、Markdown、代码块、模型连接、搜索和设置页。跟随系统使用 `prefers-color-scheme` 并响应其变化，不改动系统主题。
- 界面动画：默认启用，可关闭切换 / 生成等视觉动画；系统减少动态效果优先于此选项。不会关闭模型流式输出。
- 打开软件时：默认恢复上次打开的会话，也可显示空白新对话。保存后下次启动应用，新对话默认本机 Ollama，旧记录仍留在侧栏。
- 启动时侧栏：默认展开，可改为收起；本次窗口仍可手动切换，下一次启动使用已保存值。

设置保存在当前 WebView 的 `modelport.preferences.general.v1`，默认不主动写入；缺失字段使用兼容默认值，未知字段不保存。读取异常展示默认值和警告，不自动覆盖原配置；只有明确保存才恢复配置。保存失败不改变当前生效值。多语言、开机自启动、托盘和跨设备同步未开放；当前为简体中文，不创建 Windows 启动项。

## 聊天数据

这些操作独立生效，不需要保存配置，也不会改变配置草稿。生成期间暂停数据管理。

1. 导出聊天备份：生成 `ModelPort-chats-<时间>.json`。由桌面下载窗口完成保存，页面“已发起”不表示文件已经成功写入；请确认下载完成后再清理数据。
2. 导入聊天备份：只读取用户选择的 JSON，先校验并显示文件名称 / 会话数，确认后作为副本合并。每个会话和消息获得新 ID，不覆盖现有会话，保留当前会话和未发送草稿。重复导入会产生副本。
3. 清空聊天记录：需要填写“清空对话”确认。删除当前 WebView 的全部会话和未发送草稿，不能直接撤销；若先前完成导出，可合并导入恢复。

备份未加密，含聊天、模型名称、技能 / 知识库版本引用以及消息中已保存的检索片段。它不包含 API Key、应用配置、技能指令正文、知识库原文件或完整资料库；不要作为资料库备份使用。缺失或禁用的资料选择不会通过导入重新启用，历史来源仍按快照保留。

这里的 API Key 指系统凭据库中的密钥；聊天里自行粘贴的任何内容仍会原样进入备份，包括敏感信息，请在分享前检查文件。

支持格式 `modelport-chat-backup`、`version: 1`；最大 10 MiB、5000 会话、20000 条消息、单条正文 200000 字符。拒绝非法角色 / 模型、重复标识及超限内容；未知附加字段不进入备份。生成中消息标记为中断，不当作完整回复。导入 / 清空先持久化，失败则界面和原会话不改变。仅备份导出不联网，不发送聊天给模型。

界面使用浏览器文件输入和 WebView2 下载能力，无新增文件系统权限；下载对话由宿主管理，参考 [Microsoft WebView2 下载事件](https://learn.microsoft.com/en-us/dotnet/api/microsoft.web.webview2.core.corewebview2.downloadstarting)。

## 开发入口

- `src/lib/general-settings.ts`：配置类型、默认值、校验、版本化存储与主题解析。
- `GeneralSettingsPage.tsx`：配置草稿、文件预览、数据操作确认、保存与公共退出保护。
- `SettingsPageProps`：`generalSettings`、`generalSettingsError`、`onSaveGeneralSettings`、`chatData`、`chatBusy` 与三个数据管理回调。
- `src/App.tsx`：启动初始化、单个系统主题监听器、外观应用与聊天数据事务；不修改原生凭据、技能或知识库。
- `src/theme.css`：适配现有 `.dark` 组件约定、桌面管理页及减少动态效果；浅色保持原配色。
- `src/lib/chat-store.ts`：只保留已知字段的会话归一化、JSON 序列化 / 校验及新 ID 副本合并，沿用旧聊天存储键。
