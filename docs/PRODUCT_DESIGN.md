# ModelPort 产品设计

## 产品定位

ModelPort 是一个统一的 LLM 桌面入口。它负责对话体验、模型路由、会话管理和本地数据管理，但不销售或托管模型能力。

目标用户包括需要同时使用多家模型的个人用户、希望本地运行模型的开发者，以及需要掌控数据去向的小团队。

## 第一阶段范围

### 1. 模型连接

- 云端服务：OpenAI、Anthropic、Google、DeepSeek 和 OpenAI 兼容接口
- 本地服务：Ollama
- 每个连接单独测试可用性
- 凭据存储在系统安全凭据库
- 请求前明确展示当前服务商和模型

### 2. 对话工作台

- 流式文本回复
- Markdown 与代码块渲染
- 停止生成、重新生成和编辑后重发
- 会话级模型与参数设置
- 文件与图片附件

### 3. 本地数据

- SQLite 保存会话和消息
- 会话搜索、置顶、重命名、归档与删除
- JSON/Markdown 导入导出
- 用户可清空全部本地数据

## 界面结构

- 左侧栏：品牌、搜索、会话分组、快捷入口和设置
- 主画布：空状态或消息时间线
- 底部输入区：附件、模式、参数、模型和发送操作
- 模型连接弹窗：统一管理云端 API 和本地服务

首版视觉以浅色、低干扰和充足留白为主。主输入区始终靠近窗口底部，模型身份在发送前保持可见。

## 安全边界

- 前端组件不直接持久化明文 API Key
- Rust 层负责读取系统凭据和发起跨域模型请求
- 日志默认过滤授权头、密钥与消息正文
- 每个服务商使用独立连接配置，避免凭据误发
- 自定义服务地址需要明确的风险提示
